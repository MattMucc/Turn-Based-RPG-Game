BATTLE UI — EDITING GUIDE

Select Battle.asset and click Open live preview. Adjust preview width/height, Right turn order, Party statuses and Action spent to inspect the battle layout without entering Play Mode. The preview has example portraits/resources only; it never starts a fight or changes combat state.

COMMAND MENU
Commands.prefab controls the bottom-left command viewport and target-count display. Move its root to relocate the menu. The Scroll viewport size sets maximum list width/height; the live list shrinks to its contents and scrolls when longer. Its content VerticalLayoutGroup controls row spacing/padding.
CommandButton.prefab retains the existing menu button artwork. Edit label styling, background, outline, icon and HorizontalLayoutGroup. LayoutElement preferred height controls row height. Preserve Template Style prevents the older runtime sizing rules from replacing your edits. BattleMenuButton colour fields govern normal/highlight and enabled/disabled text. Runtime still supplies command text and keyboard/Xbox/PlayStation icons; trigger/plus glyphs are added for shortcuts.
RemainingTurn.prefab is an invisible RectTransform placement template for the standalone End Turn button shown after spending the action. Enable Action spent in the preview to see it. Target count stays above the command list, following its live height.

TURN ORDER
TopTurnOrder.prefab and RightTurnOrder.prefab set screen anchors, offsets and maximum scrolling extent. Battle.asset Order Spacing and Order Padding control portrait spacing. Current player preference chooses the orientation; Top remains the default.
TurnPortrait.prefab controls portrait size, border, HP/barrier tracks and text, and assigned-hit count. Keep bars bottom-aligned. Text uses TMP auto-sizing to fit the thin bars; change its minimum/maximum font sizes in the prefab. The blue barrier appears only when present. Portraits retain focus/pinning and Examine callbacks.

PARTY RESOURCE BOXES
PartyStack.prefab controls placement of the stack. PartyResource.prefab controls the base box width/height and arrangement of name/level, health, mana, AP, movement and status area.
Battle.asset Expanded Width, Party Spacing and Status Extra Height control dynamic emphasis and spacing. No-status boxes use the prefab's base height; status space is added only when needed. Keep the status region below the resource row.
PartyResource Status Icon Size controls the existing status badges. Badges and hover tooltips are still generated by the status system. The emphasized box follows the acting/defending party member; all displayed resource values remain live.

AUTHORING
Keep bound component references assigned. Edit prefabs in Prefab Mode while the preview stays open; unsaved edits update the preview. Save changes to use them in game.
The default Battle.asset loads automatically. BattleMenuUI has an optional Battle Layout override; it passes that layout to its HUD.
Tools > Game > UI > Create missing Battle UI templates creates missing assets without overwriting edits.

SCOPE
This pass covers command rows, target-count positioning, End Turn placement, turn order and party resources. Existing action tooltips, swap dialogs, pinned-target details, Examine, overhead displays, dodge/parry and QTE prompts remain outside this layout asset. Their gameplay behavior is preserved.

LT SHORTCUT DIMMER
ShortcutDimmer.prefab is the overlay behind the command menu while LT shortcut focus is active. Edit its Image color/alpha, sprite and RectTransform. Runtime disables raycasts so it never intercepts input. Battle.asset references this prefab; LT shortcut focus in the live preview shows it behind the commands. Action spent suppresses it, matching runtime eligibility. Existing LT/input/focus conditions are unchanged.
